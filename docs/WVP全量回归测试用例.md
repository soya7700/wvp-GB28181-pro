# WVP 全量功能回归测试用例
## 1. 验收范围

覆盖当前 `agent/wvp-mobile-station-messages` 分支已有迭代：

- WVP 后端基础能力和数据库迁移；
- AI 巡检计划、任务、结果、复核、报表和模型运营；
- 视频健康、异常聚合、工单、场景模板和算法事件；
- 餐饮场景算法预置、维护窗口、风险统计和恢复闭环；
- 移动记录仪、巡店任务、媒体留痕、整改和运营统计；
- 站内信消息闭环；
- mobile H5、微信小程序和 PC Web；
- 列表连续滚动、页面导航和空数据兼容。

## 2. 状态定义

- `通过`：已执行且实际结果符合预期。
- `失败`：已执行且实际结果不符合预期。
- `阻断`：受部署版本、数据库、网络、真机等外部条件影响，尚不能判定。
- `未执行`：本轮未进入该步骤，不能视为通过。

发布要求：所有 P0 必须通过；P1 不得存在接口 500、越权、重复数据、断链消息或无法办理的任务。
