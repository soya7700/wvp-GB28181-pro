## 测试过程中发现并修复

1. Maven 原配置固定跳过全部测试，已经恢复 Surefire 正常执行。
2. 移动端告警处置、AI 结果复核以 JSON 发送数据，而后端使用 `@RequestParam` 接收，存在跨端参数绑定失败风险；已经统一改为查询参数传递并进行 URL 编码。
3. 后端 JAR 不内置环境 YAML，配置文件位于 `target/` 同级目录。正确运行方式应在部署目录中同时放置 JAR 与 `application*.yml`，不能只复制 JAR。
