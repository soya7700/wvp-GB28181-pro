## 3. 本轮关闭的问题

1. **数据库升级遗漏和严格 SQL 报错**
   - 已确认当前 test 数据库迁移完整。
   - 模型质量与日报查询在 `ONLY_FULL_GROUP_BY` 下可正常执行。

2. **远端旧版本的 404/500**
   - 当前分支本地运行时，报告、视频健康、工单、聚合事件、场景风险、移动记录仪、线下巡店和巡店运营接口均正常。
   - 原 `10.7.2.38:18080` 的异常来源是运行中的应用版本落后，不是当前分支或数据库仍缺功能。

3. **PC Web 质量门禁**
   - 清理 5 个 ESLint error。
   - 修复用户名校验及其单元测试规则，普通非空用户名允许登录，空白用户名拒绝。

4. **设备页连续滚动**
   - 基于共享 `PageScroller` 组件复验。
   - 连续向下滚动可稳定触发两次分页加载，不再需要先上滑。

## 4. 非阻断项

- PC Web 尚有 534 个历史 warning，建议按模块逐步治理。
- PC Web 构建存在主入口和播放器资源体积提示，建议后续拆包和按需加载。
- 最新巡店、算法运营页面可继续补充浏览器自动化脚本，降低人工回归成本。
- Android、iOS、微信小程序仍需要真机或官方开发者工具验收。
- 不建议使用高版本 JDK 构建当前旧版依赖栈；项目基线继续使用 Java 8。
