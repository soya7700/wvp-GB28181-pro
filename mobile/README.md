# WVP Mobile

基于 uni-app + Vue 3 + TypeScript + Pinia 的 WVP 移动端项目。当前优先支持移动端 H5。

## 本地调试

1. 确保 WVP 后端运行在 `http://127.0.0.1:18080`；如地址不同，修改 `.env.development` 的 `VITE_PROXY_TARGET`。
2. 安装依赖：`npm install --legacy-peer-deps`
3. 启动 H5：`npm run dev:h5`
4. 浏览器访问终端显示的地址。

## 已有骨架

- 登录、退出、Token 持久化和 401 重登
- 统一 `uni.request` 请求层
- 首页、设备、通道、单路预览、推流、拉流代理和个人中心
- 五栏移动信息架构：首页、监控、告警、录像、我的
- 收藏通道、最近观看、播放状态、失败重试和基础 PTZ
- 告警列表/详情、关联实时画面
- 站内消息收件箱、未读角标、全部已读
- 告警确认、误报、完成处置和处置备注闭环
- 收藏通道的国标录像按日查询和基础回放控制
- 下拉刷新、触底分页、空数据和错误提示
- H5 开发代理及微信小程序/App 构建命令

播放器首版使用 uni-app `<video>` 并优先选择 HLS/WebRTC 地址；WS-FLV、Jessibuca、H.265 和各端原生播放器将在兼容性验证后接入统一播放器适配层。

## 当前限制

- 使用站内消息前必须执行 `数据库/2.7.5` 对应数据库升级脚本。
- 站内消息当前由设备告警自动产生，后续可扩展系统通知和运维通知类型。
- 国标录像已接入启动、暂停、恢复、倍速和停止接口，实际播放仍取决于设备与浏览器协议兼容性。
- PTZ 当前提供方向、停止和变倍，预置位接口已封装但尚未加入页面。
# 环境配置

复制 `.env.example` 为 `.env.development` 后设置后端地址。本地默认使用
`http://127.0.0.1:18080`；test 和 production 地址只保存在各自部署环境，
不要把账号、令牌或密码提交到仓库。
