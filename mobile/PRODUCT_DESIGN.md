# WVP Mobile 产品规划

## 1. 产品定位

WVP Mobile 不是桌面管理后台的缩小版，而是一套面向值班人员、运维人员和管理者的移动视频巡检与事件处置工具。

核心任务链：

> 收到异常或主动巡检 → 找到设备/通道 → 查看实时或历史视频 → 云台控制/截图/录像留证 → 记录或分享结果

首要目标：在手机上用尽量少的步骤完成“看、查、控、处置”。复杂系统配置、批量操作和长表单不是移动端首要场景。

## 2. 市场产品调研结论

参考产品包括 Milestone XProtect Mobile、AXIS Camera Station、Dahua DMSS、Wisenet Mobile、萤石云开放能力。

主流产品的共同能力：

- 实时预览：单路、多路宫格、横屏、全屏、画面缩放、清晰度切换。
- 录像回放：日期选择、时间轴拖动、事件过滤、倍速、逐帧、录像导出。
- 事件告警：推送通知、告警列表、告警详情、关联视频、确认/处置。
- 摄像机控制：PTZ、预置位、截图、本地录像、声音、语音对讲。
- 快速访问：收藏通道、最近观看、历史记录、自定义视图。
- 移动网络适配：码流/清晰度选择、弱网降级、流量提示、断线重连。
- 安全：多服务器、权限控制、生物识别、HTTPS、安全远程访问。
- 系统运维：设备在线状态、服务健康、存储状态、异常提示。

代表性差异：

- XProtect 强调告警处置、地图、书签、调查和访问控制。
- AXIS 强调实时/录像、通知、导出、双向语音和多站点。
- DMSS/Wisenet 强调多画面、PTZ 手势、事件推送、本地截图/录像和快捷回放。
- 萤石能力强调直播、回放、云台、对讲、AI 事件和多协议取流。

产品判断：WVP Mobile 的第一竞争力应是对 GB28181 设备、通道、实时流、国标录像和云端录像的统一移动访问，而不是立即覆盖所有后台配置功能。

## 3. 用户角色

### 值班人员

最高频使用者。关注在线状态、实时视频、告警、PTZ、回放和截图留证。需要操作快、按钮大、反馈明确。

### 运维人员

关注设备离线、媒体节点、推拉流状态、网络和资源占用、日志与故障定位。需要从异常快速跳到相关对象。

### 管理者

关注总体在线率、异常数量、重点点位和事件结果。需要概览、收藏、告警摘要和关键录像分享。

### 系统管理员

用户、级联、录制计划、设备配置等属于低频能力。移动端仅提供查看和必要的紧急操作，完整配置继续使用桌面后台。

## 4. 信息架构

底部导航建议固定为 5 项：

1. **首页**：系统概览、待处理异常、收藏和最近观看。
2. **监控**：组织树、设备/通道、收藏视图、多画面监控。
3. **告警**：告警列表、筛选、详情、关联视频和处置。
4. **录像**：国标录像、云端录像、收藏录像和下载任务。
5. **我的**：服务器、播放设置、通知设置、安全、运维和管理入口。

推流、拉流代理、媒体节点等运维功能从首页异常卡片或“我的 → 运维工具”进入，不占用长期底栏位置。

## 5. 功能规划

### 5.1 首页

首页只呈现能促成行动的信息：

- 系统健康：正常、部分异常、严重异常。
- 设备在线数/总数、通道在线数/总数。
- 当前活跃推流、拉流代理、媒体节点。
- 今日告警、待处理告警、离线设备。
- 收藏通道：最多展示 4～8 个，一键预览。
- 最近观看：最近 6～10 个通道。
- 快捷入口：扫一扫、设备搜索、录像查询、运维状态。

不建议首版照搬桌面 CPU、内存、磁盘等多张复杂图表。移动端先用状态和关键数字，详情页再显示趋势。

### 5.2 监控与设备

支持三种查找方式：

- 组织结构：行政区划、业务分组、设备层级。
- 列表搜索：名称、设备编号、通道编号、IP。
- 收藏/最近观看。

设备列表卡片显示：设备名称、在线状态、通道在线数、地址、最后上线/离线时间。设备详情包含基本信息、通道列表、告警记录、录像入口和运维动作。

通道卡片显示：快照、名称、在线状态、所属设备、是否正在推流/录像。点击卡片直接预览，右侧更多菜单提供收藏、录像、详情。

### 5.3 实时预览

首版单路，后续支持 2/4 宫格；手机不建议默认开放 9/16 宫格。

播放器操作区：

- 播放/停止、静音、全屏、横竖屏。
- 清晰度或码流选择：流畅、标清、高清；后端不支持时隐藏。
- 截图、本地录像、收藏。
- PTZ：方向、停止、变倍、预置位。
- 对讲/广播：按住说话，必须显示权限和连接状态。
- 快速回看：回到 30 秒前或进入当天录像。
- 流信息：协议、编码、分辨率、帧率、延迟，仅在诊断面板显示。

播放器必须有明确状态：请求中、正在连接、播放中、重连中、无权限、设备离线、协议不支持、后端超时。失败后给出“重试”和“切换协议/清晰度”，不能只有黑屏。

### 5.4 多画面监控

- 手机支持 1/2/4 宫格，平板可扩展到 9 宫格。
- 点击某格后成为当前控制通道。
- 支持保存为自定义视图，例如“东门巡检”“仓库重点”。
- 移动网络默认使用低码率，Wi-Fi 可自动切高清。
- 切后台、锁屏或页面离开时停止不必要的拉流。

### 5.5 录像

统一录像入口，但内部区分“国标设备录像”和“云端录像”。

- 按通道、日期、时间段、录像来源和收藏状态筛选。
- 月历标记有录像的日期。
- 录像时间轴支持缩放和拖动，颜色区分普通录像/告警录像。
- 播放控制：暂停、拖动、0.5/1/2/4 倍速；能力不足时仅显示可用项。
- 截图、收藏时间点、生成分享信息、下载任务。
- 下载在后台任务页显示等待、下载中、成功、失败；App 存入本地，小程序保存到相册或文件，H5 使用浏览器下载。

### 5.6 告警与事件

这是当前 mobile 骨架最需要补齐的一级模块。

- 列表按未读/待处理/已处理、等级、时间、设备、告警类型筛选。
- 告警卡片显示缩略图、告警类型、时间、设备/通道、状态。
- 告警详情展示告警前后录像、当前实时画面和设备位置。
- 操作：标记已读、确认、误报、添加备注、转交/分享。
- 从通知点击后直接进入告警详情，而不是首页。
- 相同设备短时间重复告警可合并，减少通知轰炸。

WVP 当前已有 `/api/alarm/all` 等告警查询能力，但“已读、确认、处置、备注、推送订阅”需要进一步核对或新增后端数据模型。

### 5.7 PTZ 与设备控制

- 默认使用十字方向盘，长按连续移动、松手立即停止。
- 变倍单独使用大按钮，避免误触。
- 预置位显示名称和编号，常用预置位置顶。
- 巡航、扫描、雨刷等能力根据设备能力动态显示。
- 录像开始/停止、报警复位等高影响操作需要二次确认。
- 控制失败必须显示具体原因，例如离线、超时、无权限。

### 5.8 运维中心

- 设备离线列表及持续离线时间。
- 媒体节点在线状态、负载、磁盘和流数量。
- 推流/拉流代理状态，支持启动、停止和重试。
- 平台版本、运行时间、CPU、内存、网络概览。
- 实时日志只作为高级工具，默认显示关键错误，不在手机上展示完整滚动日志。
- 一键复制诊断信息：版本、节点、流地址脱敏信息、错误码和时间。

### 5.9 我的与设置

- 当前用户、角色、服务节点。
- 多服务器配置：名称、地址、HTTPS、连接测试、快速切换。
- 播放偏好：自动/流畅/高清、仅 Wi-Fi 高清、自动播放、保持屏幕常亮。
- 流量保护：移动网络首次播放提示、流量统计或时长提醒。
- 通知设置：等级、类型、设备、免打扰时间。
- 安全：修改密码、生物识别解锁（App）、自动锁定、退出登录。
- 隐私：截图/录像水印、敏感信息隐藏。
- 关于、版本和问题反馈。

## 6. 与 WVP 当前能力的对应关系

### 可以直接基于现有后端开发

- 登录、用户信息和修改密码。
- 设备/通道列表、组织结构和状态。
- 实时播放、停止播放、抓拍。
- PTZ、预置位、巡航/扫描等前端控制。
- 广播/对讲相关播放接口。
- 国标录像查询、下载任务和进度。
- 云端录像列表、播放、收藏、变速和下载。
- 告警查询。
- 移动位置查询与订阅。
- 推流、拉流代理和媒体节点。
- 系统资源、日志、用户、级联和录制计划。

### 建议新增或增强后端能力

- 告警已读、确认、处置状态、备注和责任人。
- App/微信推送 Token、订阅规则和免打扰策略。
- 首页聚合接口，避免移动端并发请求多个统计接口。
- 收藏通道、最近观看、自定义监控视图的用户级存储。
- 设备/通道能力集接口，用于动态显示 PTZ、音频、预置位等按钮。
- 统一流能力描述：可用协议、编码、清晰度、音频、推荐播放方式。
- 移动端播放诊断接口和统一错误码。
- 分享链接的有效期、权限、水印和撤销机制。
- 操作审计：PTZ、下载、分享、启停代理、报警复位等。

## 7. 简洁 UI 规范

目标是可靠易用，不追求复杂视觉效果。

- 使用系统字体、单一主色、状态色和白底卡片。
- 正文不小于 14px，关键数字 20～28px，主要按钮高度不小于 44px。
- 列表以卡片为主，每张卡片只保留 3～5 个关键信息。
- 常用操作直接显示；危险或低频操作放入“更多”。
- 筛选使用底部抽屉，复杂表单拆成分组或分步页面。
- 所有页面必须覆盖加载、空数据、错误、无权限和离线五种状态。
- 横屏主要服务于视频；普通管理页面保持竖屏。
- 平板使用双栏布局：左侧设备/通道，右侧播放器或详情。

## 8. 关键页面流程

### 主动巡检

首页收藏 → 点击通道 → 实时预览 → PTZ/截图 → 查看当日录像 → 返回收藏。

### 告警处置

系统通知 → 告警详情 → 查看告警录像 → 切换实时画面 → PTZ 确认现场 → 标记已处理并备注。

### 录像查找

录像 → 选择通道 → 选择有录像日期 → 时间轴定位 → 倍速查看 → 收藏/截图/下载。

### 故障排查

首页异常 → 离线设备或媒体节点 → 查看状态和最近错误 → 重试代理/复制诊断信息 → 转交运维。

## 9. 迭代路线

### V0.1 工程与纵向链路（当前）

- 登录、首页基础状态。
- 设备 → 通道 → 单路预览 → 停止播放。
- 推流、拉流代理和个人中心基础页。

### V0.2 可用的移动监控（优先开发）

- 重构底栏为：首页、监控、告警、录像、我的。
- 收藏通道、最近观看、组织树和通道搜索。
- 单路播放器完整状态、重试、全屏、截图。
- PTZ 方向/变倍/预置位。
- 告警列表与详情。
- 国标录像查询和基础回放。

完成标准：值班人员可以只用手机完成日常巡检、处理一条告警并回看录像。

### V0.3 录像与处置闭环

- 云端录像、统一时间轴、收藏和下载任务。
- 告警确认、误报、备注、未读数量。
- 2/4 宫格和自定义监控视图。
- 分享、截图水印和操作审计。
- 弱网降级、断线重连和播放诊断。

### V0.4 App 化

- Android/iOS 原生播放器或插件适配。
- 后台下载、相册、推送、麦克风、常亮和生物识别。
- 真机功耗、内存、长时间播放和网络切换测试。

### V0.5 微信小程序

- 微信登录绑定或现有账号登录。
- 合法域名、订阅消息、`video/live-player` 能力适配。
- 小程序分包、文件保存、扫码和审核合规。
- 不支持的协议或高级控制提供明确降级说明。

### V1.0 完整移动端

- 多服务器/多站点。
- 地图与移动位置。
- 双向语音、广播。
- 运维中心、用户可见的系统健康与诊断。
- 平板布局、权限细化、稳定性和安全加固。

## 10. 下一开发批次建议

按产品价值与技术风险排序：

1. 重构底部导航和首页，使信息架构稳定。
2. 完成播放器状态机、协议选择、重试和全屏。
3. 接入 PTZ 基础控制与预置位。
4. 增加收藏、最近观看，并先使用本地存储实现。
5. 接入告警列表与告警详情。
6. 完成国标录像日期查询、录像列表和基础回放。
7. 再实现多画面、云端录像和下载。

不建议下一批优先做用户管理、级联配置、录制计划编辑或完整日志，它们对移动端核心任务的贡献较低。
